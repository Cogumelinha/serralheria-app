# serralheria_app

This application was developed using Flutter to showcase metalworking services, with a focus on custom garage gates.

The app allows users to browse a catalog of available models, select options such as color, and enter the desired dimensions for the gate. After making their selection, users can request a quote directly via WhatsApp, making communication with the service provider fast and convenient.

Additionally, the app includes an error reporting feature, allowing users to easily report any issues they encounter.

🚀 Features
Gate catalog visualization
Model image display
Customization (color and dimensions)
Quote request via WhatsApp
Built-in error reporting
Simple and intuitive interface
🛠️ Technologies Used
Flutter
Dart
url_launcher
📱 Purpose

To provide a practical and modern way to present metalworking services, improving communication with customers and streamlining the quotation process.
